# 16 位主机 ROM 译文版逆向笔记

对一个**由第三方重编、带中文译文的 16 位主机 RPG ROM** 做纯静态逆向的记录：解析其自研图形容器格式、定位资源装载系统、还原三层反修改保护机制，并实现去除署名水印与模式指示器的补丁。

分析对象为 4 MB（32 Mbit）卡带镜像，68K 主 CPU，图形经 VDP 输出。

## 脱敏说明

本仓库**已移除全部标识信息**，仅保留方法与结构：

| 类别 | 处理 |

| ROM 二进制、模拟器、组方说明文件 | 不入库 |

统一占位符：

- `TARGET` —— 目标作品
- `BASE-CN` —— 译文版 ROM；`BASE-UNP` —— 在此基础上由第三方移除了保护机制的版本
- `MAGIC1` / `MAGIC2` —— 两个容器魔数（4 字节 ASCII，取值已隐去）
- `WM` —— 译文组添加的署名水印；`MODE0`–`MODE3` —— 四个难度档位名称

> 因为魔数已占位化，仓库内的工具需要你自行填入目标 ROM 的魔数才能运行；文档中的偏移量均为结构信息，保持原值以便对照。

## 主要发现速览

1. **镜像不是"打补丁"产物，而是源码级重构**：与日文原版做指令级对齐后，发现引导代码逐指令一致但整体位移，绝对地址全部改写——字节级"原版覆盖"不可行。
2. **自研资源容器**：译文组用自有的 RLE 容器（`MAGIC1`）重新编码了绝大部分图形资源，导致与其他版本的正版镜像字节差异率高达 94%，尽管画面内容相同。
3. **三层反修改保护**：SRAM 密钥 + 运行时自解密 / 周期性校验 + 间接跳转劫持 / SRAM 计数惩罚。**未改动的 ROM 永不触发**，因此静态阅读汇编完全看不出异常。
4. **水印是资源不是代码**：署名水印由场景 tilemap 直接引用贴图 tile，把贴图变透明即可全场景一次性移除，无需改动 14 处以上地图数据。
5. **补丁极小**：移除 2 处水印 + 11 个模式指示器资源，仅改动 50 字节，不触及代码、指针与校验和。
